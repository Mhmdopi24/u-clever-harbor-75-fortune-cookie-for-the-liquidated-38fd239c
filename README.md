A tiny Node program that writes one fortune-cookie line for a crypto trader who just got liquidated. The fortune keeps the oracular cookie voice and lands the joke on the loss: everything is gone at 3 a.m., a smaller and luckier position still waits, and the lucky number is the liquidation price itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
